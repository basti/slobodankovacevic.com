# Repo Map

See [CONTRIBUTING.md](../CONTRIBUTING.md) for the full source file list and project details.

## Content model

- `index.html` — homepage template rendering About, Resume, and Contact sections
- `_config.yml` — structured site data: `about` paragraphs, `resume` entries, `contact` copy, and metadata
- `blog.md` — blog index page (currently `published: false`)
- `_posts/` — blog posts

## Theme and styling

- Uses [Minima 3.0](https://github.com/jekyll/minima) via `jekyll-remote-theme`
- `_includes/header.html` — custom header with nav links and dark/light toggle
- `_includes/footer.html` — custom footer with social icons and copyright
- `_sass/minima/custom-styles.scss` — site-specific style overrides
- `_sass/minima/custom-variables.scss` — Sass variable overrides

## Generated output

- `_site/` — generated by Jekyll, not a source directory
- `.jekyll-cache/` — local build cache
